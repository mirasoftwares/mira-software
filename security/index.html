Security

Last updated 25 November 2026

This page describes how Mira Software Solutions protects its clients and their information.

This page covers Mira Software Solutions and this website only. Mirwe, our product, is a separate service with its own terms and privacy policy on mirwe.com.

Card payments

When a client pays us by card, the payment is handled by a licensed, PCI DSS certified payment provider. We never see or store full card numbers.

Encrypted connections

Every page and every sign-in uses an encrypted connection.

Access

Access to client systems and data is limited to the people working on that client's project, each with their own sign-in.

Backups

Client code and project data are backed up regularly so that they can be restored if something goes wrong.

Privacy

We follow the Protection of Personal Information Act (POPIA). See our privacy policy.

Reporting a security concern

If you think you have found a security problem on this site or in software we built for you, please email info@mirasoftware.co.za. Tell us what you found and how to reproduce it, and please give us time to fix it before sharing it with anyone else.
